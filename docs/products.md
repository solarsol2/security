# 상품 구성표 (20종)

단품 16종과 세트 4종입니다. 가격은 원화, 괄호 안은 정가(할인 전)입니다.

## 카테고리
| ID | 메뉴명 | 대상 상황 |
| --- | --- | --- |
| `walk` | 귀갓길 | 밤길, 출퇴근, 혼자 걷는 길 |
| `home` | 우리집 | 자취방 현관·창문 |
| `travel` | 여행 | 공항, 숙소, 이동 중 소지품 |
| `privacy` | 프라이버시 | 몰래카메라, 택배 송장, 웹캠 |
| `set` | 세트 | 상황별 묶음 할인 |

여러 카테고리에 동시에 들어가는 상품이 있습니다(예: 도어 스토퍼 알람은 우리집 + 여행).

## 배지·상태 (목록이 다양해 보이도록 분배)
- `BEST` 많이 찾는 상품 · `NEW` 신상품 · `SET` 세트 할인 · `품절` 일시 품절 · `국내배송` 국내 보유 재고(1–2일 도착)
- 나머지는 해외배송(7–12일)입니다.
