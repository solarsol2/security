# KCOP — 일상에 안전을 더하는 안전용품 스토어

해외구매대행 기반 생활 안전용품 쇼핑몰의 프론트엔드 퍼블리싱 포트폴리오입니다.
빌드 도구 없이 HTML · CSS · Vanilla JS로 작성했으며, `index.html`을 브라우저로 바로 열어도 동작합니다.

## 페이지
| 파일 | 내용 |
| --- | --- |
| `index.html` | 메인 랜딩 — Hero, 서비스 롤링 배너, 상황별 큐레이션, 카테고리 탭 상품 그리드, 물류 프로세스, FAQ, 단체 견적 |
| `product.html?id=p01` | 상품 상세 — 옵션·수량 선택, 도착 예정일 계산, 스크롤 스파이 탭, 관련 상품 |
| `checkout.html` | 주문/결제 — 입력 검증, 개인통관고유부호 검증, 우편번호 검색, 약관 동의, 주문 완료 화면 |

## 동작하는 기능
- 장바구니(localStorage 저장) · 수량 변경 · 무료배송 진행 바 · 사이드 드로어
- 실시간 상품 검색, 데모 로그인, 단체 구매 견적 모달, 약관/개인정보 모달
- Sticky GNB, 모바일 햄버거 메뉴, 띠배너 "오늘 하루 보지 않기", 스크롤 등장 효과, 맨 위로 버튼
- 반응형(데스크톱 · 태블릿 960px · 모바일 720px), `prefers-reduced-motion` 대응

## 구조
```
assets/
  css/style.css    디자인 토큰(:root) + BEM 컴포넌트 + 반응형
  js/data.js       상품·카테고리 데이터 (상품 추가/수정은 여기서)
  js/app.js        공통: 아이콘, 장바구니, 헤더, 오버레이, 폼 검증
  js/home.js       메인 탭 필터
  js/product.js    상세 페이지
  js/checkout.js   주문/결제
```

## 배포 (GitHub Pages)
Settings → Pages → Branch를 이 브랜치 / `root`로 지정하면 됩니다.

## 이미지
모든 사진은 `assets/img/`에 WebP로 들어 있습니다 (01 Hero · 02–05 카테고리 · 06–13 상품 · 14–15 신뢰도 섹션).
상품 사진은 `assets/js/data.js`의 `imgSrc`로 연결되며, 이 값이 없으면 `img` 설명이 적힌 placehold.co 이미지가 대신 표시됩니다.
이미지를 불러오지 못하면 카테고리 아이콘 패널로 자동 대체됩니다.
